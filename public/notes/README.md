# Notes (PDFs)

To add a note:

1. Drop the PDF in this folder (lower-case, hyphens, no spaces, e.g. `docker-basics.pdf`).
2. Add one object to the top of `notes` in `src/lib/notes.config.ts` (title, blurb, tag, pages).
3. Push to `main`.

The file size is read from the PDF automatically; a note whose PDF is missing is hidden.
