# Case studies

One file per project, named after its slug in `src/lib/content.ts`
(`dyan-setu.json`, `raktsetu.json`, `csm-news-desk.json`). Edit the text
freely; no code changes needed.

- Any text that starts with `TODO:` shows on localhost (so you can see what
  is missing) but is **hidden on the live site**.
- `media.video` / `media.image` are paths inside `/public`, e.g.
  `/work/dnyansetu.webp`. Leave `video` empty if you have no clip.
- `result` items: `value` is the big number, `label` says what it counts.
  Only put real numbers here.
